## Anti-Patterns Verdict

Detector (B): `detect.mjs --json src public` → exit 2, **224 findings**. Breakdown: design-system-color 156 (advisory), overused-font 25, design-system-font 22, design-system-radius 9, bounce-easing 5, layout-transition 3, gray-on-color 2, side-tab 1, numbered-markers 1.

KEY SYNTHESIS: **156 of 224 findings (70%) are color advisories fired because the detector diffs shipped colors against DESIGN.md, and DESIGN.md is stale.** Verified: runtime canvas is consistent everywhere (`#CFE6D8` light / `#001709` dark in index.css, tailwind `sunken`, landing.html, index.html theme-color); only DESIGN.md still lists `#ECF1F7`/`#030712`. So the biggest detector cluster is a documentation bug, not a design bug. Contrast audits independently pass (1245 + 2538 + 795 samples, 0 AA/AAA failures, 0 non-text 3:1 failures).

Other detector clusters are false positives / deliberate: rounded-3xl ×73 + border+.lift ×51 = ONE card recipe repeated (a design system, not drift); songket-gold hexes in BannerCarousel = documented decorative motif; backdrop-blur = functional modal scrims, all killed under low-GPU flag; bounce-easing = named --ease-spring token for toasts/pop only (buttons migrated to expo); Fraunces/Plus Jakarta Sans confined to public/warta.html (standalone editorial page). Real-but-minor: gradient text ×3 in nobar.html (with light-mode contrast overrides), side-stripe ×1 in warta.html pull-quote.

## Overall Impression
A calm, honest, numbers-first fintech-grade UI with kampung soul and an unusually disciplined engineering culture (measured contrast, px floors, focus traps, undo, reduced-motion). It already passes its own AAA-grade audit suite. The gaps are not visual-quality gaps — they are (1) a stale source-of-truth doc that's also poisoning the detector, (2) a few information-architecture / emotional-trust choices on the surfaces the most vulnerable persona depends on, and (3) the bendahara's desktop efficiency.

## What's Working
1. Numbers-as-star is real: Sora + tabular-nums everywhere, FitAmount, StatRow suppresses color on zero ("NOL tidak berhak atas warna"), Odometer count-up + haptics = tactile trust.
2. State craft: skeletons replicate exact card anatomy (no layout jump), Toaster pauses on hover/focus with separate SR live-regions, Fab/BottomNav return on keyboard focus, ErrorState/EmptyState share one semantic anatomy.
3. Honesty engineering: SmartInsight suppresses false "-100% vs bulan lalu" alarms on empty months; Fab disabled rather than fabricate a "saldo setelah" number.

## Priority Issues

- **[P1] DESIGN.md contradicts shipped tokens (and poisons the detector).** Doc says canvas #ECF1F7/#030712; code ships #CFE6D8/#001709 (changed 24–30 Agu). Runtime is consistent and contrast passes, but DESIGN.md is the declared source of truth and 70% of detector findings are noise from this mismatch. Why it matters: future contributors and automated tools reason from a wrong reference; contrast comments computed against the old canvas mislead. Fix: regenerate DESIGN.md from current tokens; purge stale hex references in index.css/tailwind comments. Command: $impeccable document.

- **[P1] The balance auto-rotates away on touch.** Beranda hero is a BannerCarousel with saldo + 2 promo slides, autoplay ping-pong. It correctly pauses on hover/focus and stops on swipe (WCAG 2.2.2) and honors reduced-motion — but on a phone there is no hover, so the one number a warga opened the app for rotates off-screen every few seconds until they manually swipe. Why it matters: primary persona is elderly, in sunlight, wants "saldo berapa" instantly. Fix: keep saldo pinned/static; demote promos to a dismissible insight row below, or only start autoplay after the first manual swipe. Command: $impeccable layout / $impeccable distill.

- **[P2] Talangan is a 47-row wall + a public debt-shame surface.** /talangan renders all rows incl. 34 "Sudah Lunas" at once (progressive-disclosure failure), and it publishes every neighbor's name + debt in amber on a page shareable to WhatsApp. Why it matters: cognitive overload + transparency-as-shaming risk for a community product. Fix: collapse "Sudah Lunas" behind "Tampilkan 34 lainnya"; consider aggregate arrears + private own-status instead of a public per-name debt wall. Command: $impeccable distill / $impeccable clarify.

- **[P2] Deficit semantics split on Kas Hadiran.** The rose "DEFISIT" pill floats at the card's far right, detached from "-Rp395.000" at ≥560px, while a green "Sudah disetor ke Kas RT" chip sits on the same card — two conflicting emotional signals; the "why minus / is my money safe" explanation lives only behind an InfoTip. Why it matters: a minus on community money must be instantly legible and reassuring. Fix: keep the pill adjacent to the numeral at all widths; add one plain-language caption line when in deficit. Command: $impeccable clarify / $impeccable layout.

- **[P2] Bendahara has no desktop density.** App shell caps at max-w-lg (~512px, App.tsx), so the one person doing heavy data entry on a laptop gets a phone column; Kas Hadiran shows ~20 identical per-row "Unduh PDF" icon buttons (mistap noise). Fix: a wider/dense bendahara layout breakpoint; consolidate per-row export into row hover/selection or one bulk export. Command: $impeccable adapt.

## Persona Red Flags
- Elderly villager, bright sunlight: balance rotates mid-read (carousel); Talangan 47-row scroll with 13px captions; mint canvas lowers card/canvas tonal step so separation leans on hairline; hero footer stats can shrink to 9.6px (deliberate MIN_KAKI_PX floor, but the weakest readability point on the most-read surface).
- Treasurer: 512px phone column on laptop; 20 per-row PDF icons invite mistaps; bendahara write flows not verifiable from a warga session.
- First-timer: WelcomeSheet copy "Di sini Bapak-Bapak / Warga bisa" gender-excludes ibu-ibu (arisan's core demographic); if autoplay already advanced, first paint can show the promo photo instead of saldo.

## Minor Observations
- Naming: bottom-nav id `kas` labeled "Hadiran" vs h1 "Kas Hadiran" vs URL /hadiran — three names for one pot.
- Login gold focus ring + collapsed bendahara panel with `inert` = exemplary.
- Dark-mode parity strong (tonal dark nav pill, legible amber banner).
- z-index fully tokenized (no 999/9999); inline style={{}} mostly dynamic token refs; magic-number spacing confined to BannerCarousel decorative art; !important only in reduced-motion/low-GPU blocks.
- nobar.html / warta.html are standalone editorial pages with their own fonts + gradient text + side-stripe — fine for marketing register, but keep them from leaking patterns into the app.

## Questions to Consider
1. If "angka adalah bintang", why does the first screen hand the stage to a promo card every few seconds on the one device (touch) that can't hover to pause it?
2. The mint canvas was chosen because gray felt "kurang nendang" — is the real lever canvas chroma, or that between heroes the screen has no saturated anchor at all?
3. Does transparency require publishing every neighbor's name + debt on a WhatsApp-shareable link, or would aggregate arrears + private own-status keep trust without the shame wall?
